ApexPay GitOps & Zero-Downtime EKS Pipeline

The Business Challenge

The production environment experienced downtime during continuous deployments due to manual kubectl updates and uncoordinated database migrations.

Architectural Solution

    * Integrated ArgoCD Rollouts to implement Blue-Green deployment strategy. * Automated secret rotation across namespaces using GitLab CI pipelines. * Built health checks with automatic rollback mechanisms if error rates spike >2%.

Implementation Preview

apiVersion: argoproj.io/v1alpha1
kind: Rollout
metadata:
  name: apexpay-rollout
spec:
  strategy:
    blueGreen:
      activeService: prod-active
      previewService: prod-preview
